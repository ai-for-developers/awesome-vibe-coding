Factory positions its agents — "droids" — as configurable workers for an engineering organization rather than a single personal assistant: separate droids can be set up for coding, code review, incident response, or release management, each usable from the terminal or CI.

## Why it stands out

- **Multiple specialized agent roles** instead of one general-purpose assistant, matched to different stages of the engineering workflow.
- **Enterprise-grade deployment options**, including SSO, SAML/SCIM, and on-premise hosting for regulated environments.
- **CLI and CI-native**, built to run in automated pipelines as easily as interactively.

## Good for

Engineering organizations that want to standardize agentic workflows — not just individual coding help — across an entire team.
