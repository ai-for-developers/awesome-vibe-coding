OpenHands (formerly OpenDevin) is an open-source platform for running autonomous coding agents that execute real engineering work — planning a task, writing code, running commands, and applying changes — rather than just suggesting edits, with a composable SDK for building custom agent workflows on top of it.

## Why it stands out

- **Fully open source and self-hostable**, an alternative to closed, vendor-run autonomous agents.
- **Composable agent SDK**, aimed at teams building their own agent workflows rather than using a single fixed product.
- **Active open research project**, with published work behind its agent architecture.

## Good for

Teams that want an autonomous coding agent they can self-host, inspect, and extend rather than a closed cloud product.
