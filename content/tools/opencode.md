OpenCode brings an agentic coding workflow into the terminal with a polished text-user-interface, built provider-agnostic so it can run against Anthropic, OpenAI, local models, or anything else you point it at.

## Why it stands out

- **Provider-agnostic by design.** Swap the underlying model without switching tools, since OpenCode isn't tied to a single vendor's API.
- **A genuinely fast TUI.** The terminal interface is built for responsiveness, not just a wrapper around a chat loop.
- **Fully open source**, so teams can audit, self-host, and extend it rather than trust a closed binary.

## Good for

Developers who want a capable terminal coding agent without being locked into one model provider.
