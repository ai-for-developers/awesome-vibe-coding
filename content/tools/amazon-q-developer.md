Amazon Q Developer is AWS's coding assistant, combining inline code completion with an agentic mode that can plan and execute multi-file changes, review code for issues, and automate tasks like dependency upgrades — all with native awareness of AWS services and infrastructure.

## Why it stands out

- **Deep AWS integration**, from IAM-aware suggestions to automated upgrades for AWS SDK-dependent code.
- **Free tier with IP indemnification** on the paid plan, a distinct concern for enterprise legal teams.
- **Code transformation features** aimed at large-scale migrations, not just day-to-day completion.

## Good for

Teams already standardized on AWS who want a coding assistant that understands their cloud infrastructure directly.
