Zed is a code editor built from the ground up (not forked from VS Code) for raw editing and rendering speed, with AI collaboration — chat, inline edits, and agentic multi-step changes — designed in as a core feature rather than bolted on through extensions.

## Why it stands out

- **Genuinely fast**, thanks to a native, GPU-accelerated architecture rather than an Electron/VS Code fork.
- **Multi-agent and multi-model support** built into the core editor, not a single locked-in provider.
- **Open source**, with a transparent, community-visible development process.

## Good for

Developers who want AI-assisted editing without giving up editor performance, or who prefer an open-source alternative to Electron-based AI editors.
