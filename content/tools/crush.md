Crush is Charm's entry into the terminal coding agent space, pairing their signature polished TUI design with an agent that can read, edit, and run code across your project, and switch between LLM providers on the fly.

## Why it stands out

- **Charm's design pedigree.** Built by the team behind Bubble Tea and Glow, so the terminal interface is unusually refined for a CLI tool.
- **Provider-flexible.** Switch between different LLM providers and models per session instead of being locked to one vendor.
- **Session-based workflow.** Crush organizes work into resumable sessions, making it easy to pick a task back up later.

## Good for

Developers who want a terminal agent with a genuinely pleasant interface and the flexibility to change models mid-project.
