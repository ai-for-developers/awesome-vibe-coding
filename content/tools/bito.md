Bito is an AI coding assistant that pairs an IDE/CLI chat companion with an automated code review agent (AI Code Review Agent) that comments on pull requests, checking for bugs, security issues, and code standard violations.

## Why it stands out

- **PR review agent** posts contextual comments and severity-ranked findings automatically on new pull requests.
- **Multi-surface** — works as a VS Code/JetBrains extension, CLI tool, and GitHub/GitLab/Bitbucket integration.
- **Customizable rules** let teams tune what the reviewer flags to match their own coding standards.

## Good for

Teams wanting an AI reviewer that also doubles as an everyday in-IDE coding assistant.
