Copilot started as an autocomplete extension and has grown into a full assistant: inline suggestions, a chat pane, a CLI, and an agent mode that can open pull requests on its own.

## Why it stands out

- **Everywhere you already work** — VS Code, JetBrains, Neovim, Visual Studio, and GitHub.com itself.
- **Tight GitHub integration**, including agent-driven pull requests and issue-to-PR workflows.
- **Model choice** — pick between several underlying models depending on the task.

## Good for

Teams already standardized on GitHub who want AI assistance without changing editors or tooling.
