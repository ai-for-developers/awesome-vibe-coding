Same.new generates full-stack web apps from a prompt, a screenshot, or a reference URL, with the URL-to-app path in particular built to closely reproduce an existing site's look and structure rather than a loose approximation. It defaults to Next.js so frontend and backend logic live in one codebase.

## Why it stands out

- **Strong at design fidelity**, especially when cloning or closely matching an existing reference site.
- **Multiple input paths** — prompt, screenshot, or URL — depending on what you're starting from.
- **Next.js by default**, keeping frontend and backend in one deployable codebase.

## Good for

Quickly rebuilding or prototyping a site that closely matches an existing design reference.
