Codebuff is a terminal AI agent that takes a plain-language description of a task and figures out which files to read and edit across a codebase, aiming to feel less like prompting a chatbot and more like delegating to a teammate.

## Why it stands out

- **Whole-repo navigation.** Codebuff searches and reasons across a project's file tree on its own rather than requiring you to point it at specific files.
- **Natural-language task input**, so requests can be written the way you'd describe them to a colleague.
- **Credit-based pricing** that scales with usage instead of a flat per-seat fee.

## Good for

Developers who want to hand off multi-file tasks from the terminal with minimal setup.
