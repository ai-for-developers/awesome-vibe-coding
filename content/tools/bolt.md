Bolt.new runs entirely in the browser using WebContainers, so the generated app boots, installs npm packages, and runs without any server round-trip. You can prompt changes and watch the live app update instantly.

## Why it stands out

- **Instant execution.** No backend provisioning delay — the app runs client-side the moment it's generated.
- **Direct file access.** You can hand-edit any generated file alongside the AI.
- **One-click deploy** to Netlify from the same interface.

## Good for

Fast full-stack prototypes and demos where you want to see a running app within seconds of the first prompt.
