AWS Skills brings AWS-specific development practice into Claude Code — CDK patterns, cost optimization guidance, and serverless/event-driven architecture conventions.

## Why a skill for this

AWS has enough service-specific gotchas and cost traps that generic cloud advice often misses them. A skill scoped specifically to AWS and CDK keeps recommendations grounded in what actually works on that platform.

## Good for

Infrastructure-as-code work on AWS, especially CDK projects and serverless architecture design.
