Agent Skills is the open SKILL.md standard for packaging reusable agent capabilities — originated by Anthropic and now adopted across Codex, Gemini CLI, Grok Build, Cursor, GitHub Copilot, and more.

## Why a skill for this

A skill written once, in one folder-plus-markdown format, that works across many different agent products is far more valuable than a Claude-only equivalent — the same packaging effort pays off regardless of which agent a team ends up using.

## Good for

Understanding what "Agent Skills" means as a format before writing or adopting a skill meant to work across more than one AI coding agent.
