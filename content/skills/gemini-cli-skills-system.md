Gemini CLI natively supports the Agent Skills (SKILL.md) open standard, letting it load the same skill format used by Claude Code, Codex, and other compatible agents.

## Why a skill for this

A shared skills format means a skill only has to be written once to work across Gemini CLI and other compatible agents, rather than maintaining separate versions per tool.

## Good for

Gemini CLI users who want to bring in existing SKILL.md skills built for other agents, or write ones that work across multiple tools.
