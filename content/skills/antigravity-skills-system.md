Google Antigravity's skills system supports the same SKILL.md format as Claude Code and Codex, with both global (`~/.gemini/config/skills/`) and per-project (`.agents/skills/`) scopes.

## Why a skill for this

Supporting the shared SKILL.md format means skills built for Antigravity aren't locked to Google's tooling — the same skill folder is portable to other compatible agents.

## Good for

Antigravity users who want to install or author skills using Google's own supported mechanism, or reuse skills built for other SKILL.md-compatible agents.
