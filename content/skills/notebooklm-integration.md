This skill lets Claude Code chat directly with Google NotebookLM, grounding answers in a specific set of uploaded source documents rather than general knowledge.

## Why a skill for this

NotebookLM's source-grounding is useful precisely because it won't answer beyond what's in the uploaded documents. Wiring that into Claude Code keeps document-grounded research and general coding work in the same session.

## Good for

Research or writing tasks that need answers strictly grounded in a specific set of source documents.
