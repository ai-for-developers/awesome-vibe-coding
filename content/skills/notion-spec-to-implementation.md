This curated Codex skill turns a Notion spec document directly into an implementation plan and pull request.

## Why a skill for this

Specs often live in Notion, separate from the codebase, which means implementation work starts with manually re-reading and re-typing the spec. A skill that reads Notion directly removes that translation step.

## Good for

Teams that write specs in Notion and want implementation work to start directly from the source document.
