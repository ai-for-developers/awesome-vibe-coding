The Canvas Design skill packages visual design judgment: spacing systems, typographic hierarchy, color restraint, and layout composition — the kind of taste that's easy to describe but hard to consistently apply prompt by prompt.

## Why a skill for this

Left to defaults, generated visual output tends toward generic, cluttered, or inconsistent styling. A skill that encodes design principles up front produces noticeably more polished results without you having to re-explain design taste in every request.

## Good for

Generated visual artifacts, dashboards, one-off design mockups, and any output where visual polish matters and you don't want to art-direct every detail by hand.
