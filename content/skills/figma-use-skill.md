This curated Codex skill bundle wires up Figma — Code Connect, Create Design System Rules, and Generate Design — so Codex can work directly from real design files.

## Why a skill for this

Turning a Figma file into accurate code depends on knowing Figma's specific APIs, like Code Connect and design tokens, rather than guessing from a screenshot. Packaging that as a skill keeps the translation accurate.

## Good for

Implementing UI directly from Figma designs with Codex, rather than working from a static export.
