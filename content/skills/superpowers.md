Superpowers packages a battle-tested library of 20+ Claude Code skills — test-driven development, systematic debugging, brainstorming techniques, git worktree management, and root-cause tracing — installable in one shot as a plugin marketplace.

## Why a skill for this

Re-teaching Claude Code the same engineering discipline every session — write a failing test first, bisect instead of guessing, isolate work in a worktree — wastes tokens and drifts between projects. Bundling these habits as skills makes them a consistent default.

## Good for

Teams that want Claude Code to default to disciplined TDD, debugging, and git practices without re-explaining them each session.
