Frontend Slides creates animation-rich HTML presentations from scratch, or converts an existing PowerPoint deck into one.

## Why a skill for this

HTML/CSS presentations can do things static slide decks can't — real animation, interactivity, embedded live content — but building one from scratch is its own frontend project. This skill packages that so the format doesn't have to be reinvented per deck.

## Good for

Presentations that need custom animation or interactivity beyond what PowerPoint or Google Slides can do natively.
