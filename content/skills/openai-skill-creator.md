This system skill, auto-installed with Codex, scaffolds a new SKILL.md-compliant skill from a plain description of what it should do.

## Why a skill for this

Getting a skill's folder structure and frontmatter right by hand is easy to get subtly wrong. A scaffolding skill means authoring a new skill starts from a correct template instead of a blank file.

## Good for

Authoring a new Codex-compatible skill without hand-assembling the SKILL.md structure from documentation.
