OpenAI Codex's built-in skills system discovers SKILL.md skills from `~/.codex/skills/` and installs new ones via `$skill-installer`, either from OpenAI's curated catalog or any GitHub repo.

## Why a skill for this

Having a first-party install path and curated catalog, rather than only community-assembled lists, is what makes a skills ecosystem practical to actually adopt inside Codex.

## Good for

Codex users who want to install or author skills using OpenAI's own supported mechanism.
