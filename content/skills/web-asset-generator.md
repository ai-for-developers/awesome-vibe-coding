The Web Asset Generator skill produces web assets like favicons, app icons, and social media images in the sizes and formats each platform actually expects.

## Why a skill for this

Every platform — favicons, Open Graph images, app store icons — has its own required dimensions and formats, which is tedious to track by hand. A skill that already knows those specs saves re-exporting assets that come out the wrong size.

## Good for

Producing a full, correctly-sized set of site or app icons and share images without manually checking each platform's spec.
