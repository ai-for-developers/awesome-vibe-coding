Skill Seekers automatically converts any documentation website into a ready-to-use Claude skill, turning scattered docs into structured, invokable reference material.

## Why a skill for this

Most third-party libraries have documentation but no packaged skill. Automating the conversion means any well-documented tool can get a working skill without hand-authoring one from scratch.

## Good for

Adopting a new library or API quickly by turning its existing docs site into a skill instead of writing one manually.
