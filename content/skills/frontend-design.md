The Frontend Design skill packages a design-lead mindset for building web UI: pin down the subject and its audience, build a compact token system — palette, type pairing, layout concept, one signature element — then critique that plan against known AI-generic defaults before writing any code.

## Why a skill for this

Left unguided, generated UI clusters around a small set of recognizable "AI-generated" looks. A skill that names those defaults explicitly and forces a brief-specific token system before coding produces noticeably less templated results than re-explaining design taste each prompt.

## Good for

New landing pages, product UI, or any front-end build where the visual identity needs to feel deliberate and specific rather than generic.
