This is a suite of Google Workspace integration skills covering Gmail, Calendar, Chat, Docs, Sheets, Slides, and Drive, with cross-platform OAuth handling.

## Why a skill for this

Each Workspace API has its own auth flow and quirks; wiring up OAuth correctly per app is easy to get wrong. A packaged skill suite means that setup work is done once rather than per integration.

## Good for

Workflows that need Claude to read or act on Gmail, Calendar, Docs, Sheets, or Drive directly.
