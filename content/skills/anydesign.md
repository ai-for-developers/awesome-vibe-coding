anydesign analyzes any image, URL, or Figma file and produces a structured design.md capturing the full design system and component inventory, portable to other AI builders.

## Why a skill for this

Design systems usually live implicitly in a Figma file or an existing site rather than as a portable spec. Extracting that into a structured document means the design system can travel with the project instead of staying locked in one tool.

## Good for

Reverse-engineering an existing site or Figma file into a reusable design system spec for use across different AI coding tools.
